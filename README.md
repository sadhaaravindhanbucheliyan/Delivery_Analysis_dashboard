**Delivery Analysis Dashboard**
📊 Overview
This project provides an interactive dashboard built in Power BI to visualize and analyze delivery performance and logistics efficiency. By leveraging the provided dataset, the dashboard tracks key delivery metrics, identifies bottlenecks in the supply chain, and offers insights into carrier performance to support data-driven decision-making.

🚀 Features
Operational Insights: Tracks essential KPIs such as On-Time Delivery (OTD) rates, transit times, and delivery success rates.

Performance Analytics: Analyzes delivery patterns by region, carrier, and shipping method to identify operational inefficiencies.

Interactive Drill-Downs: Users can filter data by date ranges, delivery status, and specific shipping lanes to pinpoint delays.

📂 Repository Contents
Delivery_Analysis.pbix: The source Power BI file containing the data model, DAX measures, and dashboard layouts.

Delivery_Data.xlsx : The raw dataset used for the analysis, containing shipping logs, timestamps, and order details.

Dashboard_Screenshots/: Visual previews of the dashboard pages and key report metrics.

🛠 Tools Used
Microsoft Excel: Used for initial data cleansing, normalizing logistics logs, and preparing the raw dataset for integration.

Power BI: Used for building the relational data model, developing DAX measures, and creating the interactive report interface.

📈 How to Use
Clone the repository to your local machine.

Open the file: Open Delivery_Analysis.pbix using Power BI Desktop.

Update Data Source: If the data connection is broken, go to Transform Data > Data Source Settings and re-link the file path to the Delivery_Data.xlsx file located in your local folder.

Explore: Interact with the slicers and charts to analyze different delivery stages (e.g., processing time, pickup, and transit).
